# Empirical Runtime Analysis of RLS and (1+1) EA

This project contains empirical experiments on the runtime of
Random Local Search (RLS) and the (1+1) Evolutionary Algorithm.

## Experiments

### RLS
- RLS on OneMax
- RLS on LeadingOnes
- Effect of problem size n on runtime

### (1+1) EA
- (1+1) EA on OneMax
- (1+1) EA on LeadingOnes
- Effect of problem size n on runtime

### Changing Mutation Rate
The standard mutation probability 1/n is replaced by c/n.

The experiments investigate the effect of c on runtime for:
- OneMax
- LeadingOnes
